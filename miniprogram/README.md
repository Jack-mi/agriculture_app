# 谷雨记 · 微信小程序

种粮大户的农田电子账本：地块 × 作物 × 种植季，**收支双向记账**（支出 5 类 + 收入类型，可多季分摊）+ 农事日志（每日农情 / 作业 / 农资 / 气温 / 降雨 / 风力 / 墒情），自动统计积温、降雨与**净收益**。

## 快速运行
1. 打开「微信开发者工具」→ 导入项目 → 选择本 `miniprogram/` 目录。
2. AppID：测试可用「测试号」；正式发布请把 `project.config.json` 里的 `appid` 换成你的。
3. 开发者工具中勾选「不校验合法域名」即可直接拉天气调试。

## 口径
- 积温 = 播种日到收获日（在种则到今天）每日平均气温之和（含负值，同时展示仅 0℃ 以上的值）。
- 固定资产（机械、土地流转）计入当季总成本。
- 冬小麦跨年：季以播种日为起点，天数/积温/降雨跨年连续累计，标签显示"2026–2027 小麦"。
- 成本分摊：一笔开销只录一次，按金额分摊到一个或多个种植季（allocations），统计与流水均按本季分摊金额；删除季/地块只移除对应分摊。
- 农事日志日历：播种日 → 收获日/今天逐日连续，无记录日期显示「本日未记录」可补记；旧施肥记录自动映射为化肥使用明细。
- 收支方向：`costs[i].dir` 为 `'out'`（支出，缺省）或 `'in'`（收入）。旧数据没有 `dir` 一律按支出处理，零迁移。
- 净收益 = Σ收入 − Σ支出（均按分摊后金额）。赊账（`costs[i].debt`）仍计入成本/收入，只额外记「钱收没收到 / 付没付出」；销账支持部分金额，累计够了才置已结清。
- 库存：农资在 `tags.stock`（单文档同步，无新增云端集合）；记事里填了农资用量且库存有同名品名时，按 `用量 × 完成面积` 自动扣减；编辑记事会先回滚上次扣减再重扣，删除记事不回滚（东西已经撒地里了）。
- 周期账：存在 `tags.recurring`，到日子只生成待记提醒，不自动落账；分期每期金额 = 总额 / 期数，尾差进最后一期（复用 `splitBy`）。
- 回收站：删除走软删（`deletedAt`），云端用 upsert 同步而不是 remove，换设备也能恢复；30 天后本机清理。
- 键盘等本机偏好存 `guyuji_kp_pref`，不进云端，换手机回默认。
- 预算：存在 `seasons[i].budget = { total, perMu, cats }`（直接挂季记录，不新增集合）。有效预算 = 总预算优先，其次「每亩目标 × 地块面积」；本季支出 ≥ 90% 时首页与账本会提醒。
- 资金账户：存在 `tags.accounts = [{ key, name, init }]`（单文档同步）；账目挂 `costs[i].account`。余额 = 期初 + 实收 − 实付，**挂了赊账的只算已销账金额**，没挂账户的账不计入。账本页可按账户筛选。
- 资产负债：净资产 = 资金账户余额 + 库存估值（在库 × 最近均价）+ 应收 − 应付。

## 自检
```bash
node --test miniprogram/tests/*.test.js   # 数据与统计口径（51 个用例）
node scripts/check-miniprogram.js         # 页面文件齐不齐、wxml 事件有没有对应函数、模块方法有没有写错
```
- 风力 = Open-Meteo 当日最大风速（m/s），逐日展示 + 全周期最大值，不累计；旧天气记录无风力显示「—」。

- 记账计算来源：`costs.calc = {mode:'perMu'|'perDay', unitPrice, mu|people}`、`costs.expr`（连加算式）、`costs.split`（多季分摊方式）仅用于展示/回填，**落账永远以 allocations 为准**；按亩均摊按分计算，最后一季吸收尾差。
- 作物二级类目 = 品种（`seasons.variety`，选填，≤20 字）：开季时可点选「用过的 / 常见品种」或自由输入，季详情「信息」页可随时补填/修改/清空；展示为「玉米 · 登海605」。常见品种建议见 `const.VARIETIES`。
- 常用账存于 `tags.templates`（随 tags 单文档同步，不新增集合）；「恢复默认类型」不清除常用账。
