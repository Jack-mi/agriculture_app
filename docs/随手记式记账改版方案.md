> 基线：`Jack-mi/agriculture_app@main`（含成本多季分摊 `allocations`、农事日志连续日历、风力、outbox 同步）。
> 原则：**只借交互，不借视觉**（保留麦绿 / 纸色 / 大字号）；**不新增云端集合**、不引第三方依赖。
> 配套视觉稿：`谷雨记 记账改版方案.html`
> **状态：P0 + P1 已落地到 `miniprogram/`，单测 16/16 通过；P2（语音）未做。**

## 2. 数据结构变更（向后兼容，旧数据零迁移）

```js
costs[i] += {
  calc: { mode: 'perMu', unitPrice: 15, mu: 80 } | undefined,  // 按亩计来源；金额仍以 allocations 为准
  expr: '320+180+95' | undefined                               // 键盘连加表达式，仅展示
}
db.tags.templates = [{                                          // 常用账：挂在 tags 单文档里，走现有 tags upsert 同步，不建新集合
  id, name: '无人机飞防', cat: 'mach', sub: '飞防',
  unitPrice: 15, mode: 'perMu' | 'fixed', amount: 0,
  allocMode: 'current' | 'byArea', seasonIds: [], note: ''
}]
```
- `allocations` 语义不变：**永远是最终落账金额**；`calc/expr` 只是"怎么算出来的"。
- 按亩均摊取整：按面积比例算到分，**最后一季吸收尾差**，保证 Σ = 总额。

## 4. 交互细则

- **记一笔默认态**：带入当前季；类别记忆上次选择（`wx.setStorageSync('guyuji_last_cat')`）；从农事日志「保存并记花费」进入时沿用现有 `cat/sub/logId/note` 参数，并把 `areaMu` 带入按亩计的亩数。
- **按亩计**：开启后金额区变「单价 ¥15 /亩 × 80 亩 = ¥1,200」；亩数默认 = 已选分摊季的地块面积之和，可改。
- **完成**：金额 > 0 才可点；有表达式时先「=」求值，再点才保存。「再记一笔」= 长按完成 / 或 chip 行末「再记」开关。
- **日历格**：当天花费 ≥ 1 显示金额（>1 万显示「1.2万」）；有降雨显示蓝点；在季内且无记事、无账显示灰色「未记」；季外日期置灰不可点。
- **弱网**：全部本地计算，无新增网络依赖（P2 语音除外）。

## 6. 验收用例

1. 飞防：单价 15 × 80 亩，勾选村东大块(52 亩)+河边地(28 亩)按亩均摊 → 780 / 420，两季账本各自计入，Σ = 1,200。
2. 连加：320+180+95 → 完成显示 595，流水备注区显示表达式。
3. 日历：跨年冬小麦 12 月 → 1 月翻页连续；季外日期不可点；未记日可一键补记，日期自动带入。
4. 常用账：存「无人机飞防 15 元/亩」，首页点 chip → 进入记一笔已填好单价，只需确认亩数。
5. 旧数据：无 `calc/expr/templates` 的库打开不报错，统计金额不变。
