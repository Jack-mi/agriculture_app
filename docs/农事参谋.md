# 农事参谋（种植决策）· 一期落地说明

对应设计稿：`田祖记 种植决策设计方案.html`。数据前提：只有天气自动获取，其余全部农户录入；不用遥感和传感器。

## 结构
| Tab | 维度 | 内容 |
|---|---|---|
| 今天 | 时间 | 天气与预警 · 待办（马上办 / 这周 / 往后折叠）· 生育期小卡 · 最近记的 · 常驻「记一笔账 / 记今天的活 / 🎤」；没事时写「今天地里没有要紧的事」+ 下一件预告 |
| 地块 | 空间 | 季详情新增第一个标签页「参谋」：生育期（有效积温）· 下一阶段预计日期 · 最近一次长势 · 本块地任务 · 「跟参谋说」 |
| 我的 | — | 不变 |

## 任务（农事的最小单元）
- **来源**：规则（生育期 / 天气 / 你的记录）· 你说的 · 参谋建议（点「加成任务」才生成）
- **时机**：今天页每次显示时刷新（预报每天拉一次并缓存）；开季、保存日志、校准、对话确认后对该季重算。全在手机上跑，不依赖后台定时任务
- **生命周期**：open → done（去记一笔 / 对话补记）/ dismissed（对话说不用）/ expired（规则不再命中或过期 3 天）
- **去重**：规则任务 id = `seasonId#ruleKey`，同季同规则只一条；农户改过日期（userDue）的，刷新不覆盖日期
- **规则表**：`utils/rules.js`，16 条（小麦 7、玉米 3、通用天气 3、通用记录 2、+ 抢收类按天气升级）

## 生育期
- 有效积温：小麦 `max(0, T)`；玉米 `max(0, min(T,30) − 10)`。与现有「积温」（日均温直接累加）并存
- 阈值：`utils/growth.js` 的 `STAGES`（**示意值，上线前按品种标定**）+ `VARIETY_FACTOR` 品种系数
- 预测：实况 + 16 天预报；超出预报用近 7 日均温外推；越冬等停滞期不给日期
- 校准：对话说「都三片叶了」→ 校准卡 → 记录偏移（`seasons.stageCalib`），后续阶段与任务整体顺延

## 天气预警（只做天气类）
| 类型 | 触发 |
|---|---|
| 连阴雨 | 连续 ≥3 天日降雨 ≥5mm 且累计 ≥30mm；或单日 ≥50mm |
| 降温霜冻 | 最低 ≤0℃，或 48 小时降温 ≥8℃ |
| 大风 | 日最大风速 ≥10.8m/s |
| 干热风 | 5–6 月，最高 ≥32℃ 且风速 ≥3m/s |

预警按「天气 × 作物阶段」拆到各地块，并直接由规则生成任务。

## 跟参谋说（LUI）
- 入口：今天页 🎤 · 任务详情（带上这条任务）· 季详情「参谋」（带上这块地）
- 对象与动作（白名单，`utils/chat.js` `ACTIONS`）：
  - 任务：新建 `task.create` · 调整 `task.update` · 删除 `task.dismiss`（可「以后都不用」→ 抑制该规则）· 完成（`log.create` 带 taskId）
  - 地块：问建议 → 建议卡「加成任务」· 语音记事 `log.create` · 语音记账 `cost.create`（按亩计 / 按亩均摊）· 校准 `stage.calibrate` · 查询（花了多少 / 上回哪天 / 什么阶段）
  - 记住 / 忘掉：`memory.add` / `memory.remove`
- **每个写操作都要农户点确认卡片**，`chat.execute(card)` 是唯一写入口；细改走已有记事页 / 记一笔页
- 理解：默认**本地规则解析**（离线可用，`utils/nlu.js` 支持中文数字、相对日期、按亩单价、雇工、农资用量、机械）。在 `app.js` 设 `globalData.aiModel` 后先走**云开发 AI 大模型**，其输出同样经白名单转卡片；记账金额必须能被本地解析复核
- 语音：`app.json` 已声明微信同声传译插件 `WechatSI`，需在小程序后台「设置 → 第三方设置 → 插件管理」添加；未添加时自动降级为打字

## 合规
- 推荐：只列 `utils/pesticide.js` 中已登记、且登记作物匹配的产品；本地限用的列为「不推荐」并写理由
- 记录：记事页填农药名和用量时校验，超量 **只提醒、不拦保存**
- 登记表为示意（登记证号占位），上线接入 ICAMA 月度数据
